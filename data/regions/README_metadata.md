# Метаданные для /regions/[region]

Изменены только два файла.

1. `region-name-forms.ts`
   - положить в `data/regions/region-name-forms.ts`;
   - содержит винительный и предложный падежи для всех 71 текущих региональных route-slug.

2. `page.tsx`
   - заменить `app/regions/[region]/page.tsx`;
   - добавлена `generateMetadata()`;
   - существующие overview, ProductList, климатические таблицы, JSON-LD и терминалы сохранены.

Шаблон:
- title: `Калориферы и отопительное оборудование в <предложный> | Завод Т.С.Т.`
- description: использует винительный и предложный падежи региона + `region.capital.name`;
- keywords: формируются по согласованному шаблону.

`title.absolute` используется намеренно: если в корневом layout есть `title.template`,
к заголовку региональной страницы не будет второй раз дописано название сайта.
